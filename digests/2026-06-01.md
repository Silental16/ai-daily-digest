**🤖 Claude & Anthropic**

• **Claude Opus 4.8 — первая рабочая неделя** — После запуска 28 мая модель стала дефолтной для Max, Team Premium, Enterprise и Anthropic API. Ключевые возможности: 1M токенов контекста по умолчанию, 128k max output, adaptive thinking (reasoning только когда нужен), mid-conversation system messages без сброса кеша, рефузальные категории в `stop_details`. Fast mode на Opus 4.8 — $10/$50 за млн токенов, в 3× дешевле предыдущего поколения.
  ↳ https://platform.claude.com/docs/en/release-notes/overview

• **С 15 июня Agent SDK уходит в отдельный биллинг** — Официально подтверждено: использование `claude -p` и Agent SDK больше не входит в лимиты подписки. Отдельный monthly credit pool: $20 для Pro, $100 для Max 5x, $200 для Max 20x. Биллинг по полным API-тарифам, без роллоувера. Параллельно: оригинальные Claude Sonnet 4 и Claude Opus 4 (от мая 2025) снимаются с API тоже 15 июня.
  ↳ https://codersera.com/blog/anthropic-june-2026-billing-change-claude-code/
  ↳ https://www.buildthisnow.com/blog/guide/mechanics/claude-billing-change-june-2026
