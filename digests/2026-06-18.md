**🔥 Главное**

• **Google убила Gemini CLI: сегодня последний день** — 18 июня Gemini CLI официально прекратил работу для пользователей Google AI Pro и Ultra. Ему на смену пришёл закрытый Antigravity CLI — инструмент для агентной платформы Gemini 3.5. Developer community ожидаемо взбунтовалось: Gemini CLI был Apache 2.0, Antigravity — проприетарный. Google объяснила переход тем, что «современные задачи требуют нескольких агентов, работающих параллельно», но open-source замены не предложила. Для enterprise (Gemini Code Assist Standard/Enterprise) и API-клиентов с платными ключами Gemini CLI пока остаётся доступным.

**🤖 Claude & Anthropic**

• **Claude Design: масштабный апдейт, вышедший 17 июня** — Двунаправленная синхронизация с Claude Code через команды `/design-sync` и `/design` — теперь дизайн-прототип можно передать в Claude Code одним действием, и агент начнёт программировать интерфейс с уже готовой базой. Импорт design systems из GitHub-репозиториев, дизайн-файлов и raw uploads. Прямое редактирование на холсте (direct canvas editing). Корпоративная роль admin блокирует компоненты для соблюдения брендбука. Экспорт расширен до Adobe, Canva, Miro. Продукт набрал 1 млн+ пользователей за первую неделю бета-теста.

**💡 Инсайт дня**

18 июня 2026 года — день, когда open-source проиграл ещё одну битву. Google закрыла Gemini CLI (Apache 2.0) и заменила его проприетарным Antigravity — без открытого кода, без права форкнуть. Одновременно Anthropic строит путь к IPO с оценкой, превышающей ВВП большинства стран. Паттерн один: AI-инфраструктура монополизируется. Каждый инструмент, который сначала выпускается открыто для привлечения разработчиков, рано или поздно уходит за paywall или превращается в closed-source. Claude Design + Claude Code теперь полностью замкнуты в Anthropic-экосистеме с bidirectional sync — удобно, но lock-in намеренный. Разработчикам стоит параллельно инвестировать в открытые альтернативы: OpenCode, OpenClaw, Aider.
