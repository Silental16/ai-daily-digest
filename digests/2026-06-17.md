**⚡ Инструменты & Агенты**

• **Claude Code — крупный Feature Drop: nested agents, /cd, safe mode** — Релиз от ~17 июня добавляет три принципиальных возможности. `/cd` переносит сессию в другую рабочую директорию без пересборки prompt-кэша. Nested sub-agents: агенты теперь могут самостоятельно порождать дочерние агенты — это открывает полноценную мультиагентную оркестрацию внутри одной сессии. `--safe-mode` / `CLAUDE_CODE_SAFE_MODE` запускает Claude Code без CLAUDE.md, skills, plugins, hooks и MCP-серверов — для дебага сломанных конфигов. Также: `fallbackModel` с цепочкой до трёх резервных моделей при перегрузке основной.

  ↳ https://releasebot.io/updates/anthropic/claude-code
