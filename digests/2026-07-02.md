🗞 **AI Daily Digest — 2 июля 2026**

**🔥 Главное**

• **Anthropic запустил Claude Science — AI-воркбенч для учёных** — Новый продукт оптимизирует Claude под задачи биомедицинских исследований и фармацевтических лабораторий. Внутри: 60+ готовых функций для геномики, single-cell анализа, протеомики, структурной биологии и хемоинформатики, плюс предсказание 3D-структур белков. Dario Amodei прямо говорит: «Claude Science сделает для наук о жизни то, что Claude Code сделал для программирования». Бета открыта, гранты до $30K, заявки принимаются до 15 июля.
  ↳ https://www.anthropic.com/news/claude-science-ai-workbench

• **OpenAI анонсировал GPT-5.6 Sol, Terra и Luna — но не для всех** — Три модели нового поколения вышли в ограниченный preview: Sol для frontier-задач и долгосрочных агентных воркфлоу, Terra для повседневной работы (вдвое дешевле Sol), Luna — самая быстрая и дешёвая. Доступны лишь ~20 компаниям, одобренным правительством США. Sol стоит $5/M input и $30/M output, устанавливает новый SOTA на Terminal-Bench 2.1 (83.4%). OpenAI запускает Sol на инфраструктуре Cerebras — до 750 токенов в секунду.
  ↳ https://openai.com/index/previewing-gpt-5-6-sol/

**🤖 Claude & Anthropic**

• **Claude Code: background-агенты теперь работают по-новому** — С последним апдейтом агенты, запущенные из `claude agents`, больше не останавливаются и не спрашивают разрешения: они сами делают коммит, пушат ветку и открывают draft PR по завершении. Claude in Chrome вышел в general availability. Встроенный Explore-агент теперь наследует модель основной сессии (раньше работал на Haiku). Исправлены: залипание remote-сессий при перезапуске воркера, мерцание терминала в JetBrains IDE 2026.1+.
  ↳ https://code.claude.com/docs/en/changelog

• **Claude Sonnet 5 — новый флагман серии Sonnet** — Вышел 30 июня, сейчас активно используется. Самая агентная модель Sonnet на сегодня: заметный прирост в рассуждениях, tool use и кодинге. Вводная цена $2/M input действует до 31 августа. Приближается к уровню Opus 4.8 по качеству.
  ↳ https://www.anthropic.com/news

**⚡ Инструменты & Агенты**

• **Mistral OCR 4 — enterprise-ready document AI** — Вышел 23 июня, сейчас активно внедряется в production. Поддерживает 170 языков, возвращает bounding boxes + метки блоков (paragraph, table, equation, code…), confidence-скоры, умеет self-hosting в одном контейнере. Цена: $4 за 1000 страниц, $2 через Batch API. Win rate над конкурентами — 72% по оценкам независимых аннотаторов.
  ↳ https://mistral.ai/news/ocr-4/

• **Acti — аgentic mobile keyboard занял #1 на Product Hunt** — Клавиатура для смартфона, которая изнутри текстового поля умеет подтягивать ссылки, документы, расписание, профили и ссылки на встречи. Продемонстрировала, что агентные паттерны работают не только в десктопных IDE.
  ↳ https://www.producthunt.com/

• **Claude Code достиг $2.5B ARR** — По данным аналитиков, терминальный инструмент Anthropic генерирует $2.5 млрд в аннуализированной выручке — только с продаж CLI и API. Это делает его одним из самых быстрорастущих developer tools в истории.
  ↳ https://www.mindstudio.ai/blog/claude-code-2-5-billion-annualized-revenue-terminal-tool

**🌐 Индустрия**

• **UBTECH UWORLD U1 — первый серийный человекоподобный робот** — Китайская компания запустила коммерческие продажи: три модели (U1 Lite, Pro, Ultra), 88 степеней свободы, биомиметическая кожа, 20+ распознаваемых эмоциональных состояний. До презентации уже 13 361 предзаказ. Отгрузка — с 16 сентября. Ultra-версия стоит ~$145K. Компания позиционирует U1 как «компаньона» против одиночества, но индустриальные применения очевидны.
  ↳ https://technode.com/2026/07/01/ubtech-unveils-consumer-humanoid-robot-u1-says-orders-secure-11000-ahead-of-first-deliveries/

• **MCP 2026-07-28 Release Candidate — протокол становится stateless** — Спецификация Release Candidate уже доступна. Главное изменение: MCP переходит на stateless-архитектуру на уровне протокола — стандартный HTTP, load balancers из коробки. Новое расширение Tasks позволяет серверу вернуть handle вместо блокирующего ответа. OAuth 2.1 стал обязательным. Финальная версия выйдет 28 июля.
  ↳ https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/

• **X (Twitter) запустил официальный MCP-сервер** — Теперь AI-инструменты могут обращаться к X API через MCP, используя разрешения аккаунта пользователя. X присоединился к GitHub, Slack, Notion, Stripe и Salesforce.
  ↳ https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/

**💡 Инсайт дня**

Claude Science — это не просто «модель для науки», это полноценный воркбенч с интегрированными инструментами, аудируемыми артефактами и доступом к вычислительным ресурсам. OpenAI ответил на это GPT-Rosalind ещё в апреле, но Anthropic заходит с акцентом на воспроизводимость и аудит — что критично в регулируемой фармацевтике. Паттерн ясен: вертикализация AI продолжится — право, финансы, медицина — каждая профессия получит свой «Code».
