💰 **Indie Story**

**Кевин Эндрюс — иммиграционный адвокат, который построил юридический стартап с нулевым кодом за 524 часа диалога с Claude**

Кевин Эндрюс — практикующий иммиграционный адвокат без какого-либо опыта программирования. В начале 2026 года он решил попробовать Claude Code не потому, что «интересовался AI», а потому, что устал платить подрядчикам за простые инструменты. Результат превзошёл все его ожидания.

За ~524 часа разговоров с Claude (он тщательно вёл статистику) Кевин построил полноценную solo юридическую практику с AI-поддержкой: автоматизированный приём клиентов, генерация иммиграционных форм с проверкой, трекинг дел, клиентский портал. Ни одной строки кода он не написал сам — буквально. Вся кодовая база создана Claude Code итеративно, через описание проблем на обычном языке.

Но самое интересное случилось дальше. Сайд-эффектом проекта стала SaaS-платформа для AI-автоматизации юридических воркфлоу, которую Кевин стал предлагать другим небольшим юридическим фирмам. Параллельно — его история разошлась в сети, и в итоге он получил оффер на позицию Chief Legal Engineer в AI-стартапе. Позицию, которой ещё год назад не существовало.

Кевин называет 524 часа «обучением через делание»: первые 50 часов были мучительными — он не понимал, как объяснять задачи так, чтобы Claude понял контекст. Потом щёлкнуло: нужно описывать не «сделай кнопку», а «когда пользователь нажимает Submit, нужно валидировать поле паспорта по формату ICAO, затем сохранить в базу, затем показать следующий шаг». Это и есть context engineering в действии.

Главный takeaway: порог входа в технологии окончательно снесён. Кевин не стал «немного программистом» — он остался юристом, который теперь строит software. Разница критическая: его продукт сделан человеком с глубокой доменной экспертизой в иммиграционном праве, и это то, что не мог сделать ни один outsource-разработчик без месяцев онбординга.
