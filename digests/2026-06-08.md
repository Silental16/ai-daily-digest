🗞 **AI Daily Digest — 8 июня 2026**

**🔥 Главное**

• **Apple анонсировала Siri AI на базе Google Gemini — главное событие WWDC 2026** — На ежегодной конференции для разработчиков Apple полностью перезапустила Siri под брендом «Siri AI». Ассистент теперь работает на модели Google Gemini в рамках многолетней сделки стоимостью около $1 млрд/год. Siri наконец получила нормальный режим диалога: можно переписываться текстом, прикреплять документы и изображения, а ответы разворачиваются в полноценный чат. Доступность через Private Cloud Compute Apple. Доступно только в США — Европа и Китай пока заблокированы регуляторами. iOS 27, macOS 27 и сопутствующие ОС выйдут осенью, публичная бета — в июле.
  ↳ https://www.macrumors.com/2026/06/08/apple-announces-siri-ai/

• **Google заплатит SpaceX $920 млн в месяц за вычислительные мощности** — Сделка, объявленная 5 июня, стала настоящим шоком для рынка: Google Cloud арендует у SpaceX 110 000 GPU NVIDIA с октября 2026 по июнь 2029 — итого около $30 млрд. Официальная причина: «рекордный спрос на платформу агентов Gemini Enterprise, превысивший все ожидания». Сделка подтверждает, что AI compute сегодня — дефицитный ресурс, который крупнейшие игроки готовы покупать у кого угодно, включая ракетные компании.
  ↳ https://techcrunch.com/2026/06/05/google-will-pay-spacex-920m-per-month-for-compute/

**🤖 Claude & Anthropic**

• **Сбой Claude 7 июня: ~2 часа даунтайма, расследование утечки данных** — Накануне Anthropic столкнулась с двухчасовым отказом моделей Opus 4.7 и Opus 4.8. После восстановления работы компания объявила о расследовании сообщений о возможной утечке данных клиентов в ходе инцидента. Детали пока не раскрыты.
  ↳ https://cybernews.com/ai-news/claude-outage-resolved-anthropic-opus-model-errors/

• **Claude Code: Dynamic Workflows и Auto mode на облачных платформах** — Свежие обновления Claude Code включают Dynamic Workflows — режим, при котором Claude сам оркестрирует работу десятков и сотен агентов параллельно. Auto mode теперь доступен на Bedrock, Vertex и Foundry для Opus 4.7 и 4.8. Добавлена автозагрузка плагинов из `.claude/skills`. Важно: с **15 июня** программная и агентная генерация через Claude Code переходит на отдельный кредитный пул по полным API-тарифам — проверьте бюджеты заранее.
  ↳ https://releasebot.io/updates/anthropic/claude-code

**⚡ Инструменты & Агенты**

• **MCP Go SDK обновлён 8 июня** — Официальный Go SDK для Model Context Protocol (разрабатывается совместно с Google) получил обновление. Экосистема MCP продолжает расти: более 10 000 активных публичных серверов, поддержка встроена в ChatGPT, Cursor, Gemini, Microsoft Copilot и VS Code. Фокус 2026-роадмапа — масштабируемость транспорта, agent-to-agent коммуникации и enterprise-готовность (SSO, аудит-треилы, конфигурационная переносимость).
  ↳ https://github.com/modelcontextprotocol

• **Trending на GitHub: last30days-skill и taste-skill** — В топе трендов сегодня два AI-скилла для агентов. `last30days-skill` агрегирует данные из Reddit, X, YouTube, HN, Polymarket и веба и синтезирует «заземлённые» резюме по любой теме. `taste-skill` — буквально «вкус» для LLM: останавливает генерацию скучного generic-контента, задавая агенту эстетические ориентиры.
  ↳ https://github.com/trending

Это первый прецедент, когда Apple официально открывает экосистему для конкурентов — пусть и в ограниченном виде.

**💡 Инсайт дня**

WWDC 2026 и сделка Google–SpaceX вместе складываются в одну большую картину: война за AI-инфраструктуру вышла на уровень межкорпоративных альянсов, которые раньше казались немыслимыми. Apple — партнёр Google по Siri. Google — клиент SpaceX по GPU. xAI, SpaceX и Google в одной сделке. Это не конкуренция в привычном смысле — это гонка за дефицитным ресурсом (compute), в которой прежние rivalries отходят на второй план. Одновременно Anthropic показала, что даже лидеры рынка уязвимы — двухчасовой даунтайм с намёком на утечку данных ударил по репутации ровно накануне главного tech-дня года.
