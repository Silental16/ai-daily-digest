🗞 **AI Daily Digest — 9 июля 2026**

**🔥 Главное**

• **GPT-5.6 Sol/Terra/Luna вышли публично — 750 tok/s на Cerebras и агрессивный ценник** — Вчера был анонс «завтра», сегодня — реальный релиз. После 12-дневного правительственного review (стартовал 26 июня) OpenAI открыла доступ всем. Флагман Sol стоит $5/$30 за миллион токенов, крутится на wafer-scale-железе Cerebras со скоростью до 750 tok/s (~15x против GPU), даёт 1M контекста, 128K output и knowledge cutoff 16 февраля. Из нового — Programmatic Tool Calling и встроенная multi-agent-оркестрация. Terra ($2.50/$15) — уровень GPT-5.5 вдвое дешевле, Luna ($1/$6) — бюджетный tier для высоконагруженных пайплайнов. Сэм Альтман признал, что во время переговоров с правительством OpenAI «внесла много изменений».
  ↳ https://openai.com/index/gpt-5-6/

• **Meta Muse Spark 1.1 — первая в истории платная модель Meta и первый пост Цукерберга в X за 3 года** — Meta Superintelligence Labs запустила Muse Spark 1.1 через новый Meta Model API. Это ПЕРВАЯ коммерческая AI-модель Meta за деньги. Мультимодальная (текст, картинки, видео), computer use, 1M контекста, ценник $1.25/M input и $4.25/M output — очень конкурентно. API говорит одновременно в формате OpenAI SDK И Anthropic Messages, новым юзерам дают $20 кредитов. Ради анонса Марк Цукерберг впервые за три года запостил в X — сигнал, насколько для Meta это стратегический разворот от «раздаём Llama бесплатно» к платному API.
  ↳ https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/
  ↳ https://techcrunch.com/2026/07/09/meta-enters-the-crowded-ai-coding-battle-with-muse-spark-1-1/

Уход ключевой фигуры оставляет Альтмана один на один и с продуктом, и с правительственными переговорами.

**🤖 Claude & Anthropic**

• **Claude Reflect — бета-дашборд о том, как вы пользуетесь Claude** — Anthropic запустила Reflect (web + desktop): панель показывает ваши темы, пиковые дни и часы, паттерны за 1/3/6/12 месяцев. Есть блок «Time and focus» с напоминаниями о перерывах, quiet hours и рефлексивными вопросами вроде «Что одно вы хотите продолжать делать сами?». Доступно Free, Pro и Max с включённой Memory. Формально — забота о mindful-использовании; по факту — ещё один крючок вовлечения, встроенный прямо в продукт.
  ↳ https://www.anthropic.com/news/reflect-with-claude
  ↳ https://techcrunch.com/2026/07/09/anthropics-new-claude-feature-is-quietly-selling-you-on-ai/

• **Claude Code v2.1.206** — Подсказки путей в `/cd`; `/doctor` переработан и теперь чинит проблемы сам, а не только рапортует; улучшено качество `/code-review` на Opus 4.8; Ctrl+X — навсегда удалить завершённые сессии. Фиксы: MCP `request_timeout_ms` больше не игнорируется в свежих сессиях, OAuth MCP-серверы не требуют повторной авторизации после одного неудачного refresh. Background-агенты апгрейдятся сразу после апдейта Claude Code, а `/commit-push-pr` авто-разрешает пуш в настроенные push-remotes.
  ↳ https://code.claude.com/docs/en/changelog

Глобальный роллаут. Первый крупный шаг рекламной платформы такого масштаба к обязательному раскрытию AI-происхождения контента.

**💡 Инсайт дня**

9 июля у API-войн открылось сразу три новых фронта за один день. Meta впервые в истории берёт деньги за модель через собственный Model API — и сразу говорит на двух чужих диалектах, OpenAI SDK и Anthropic Messages, то есть прямо целится в чужих разработчиков. OpenAI выпускает GPT-5.6 после правительственного review и тоже демпингует по цене. А Ollama в тот же день поднимает $65M, доказывая, что «запусти локально» — это не нишевая забава, а позиция-хедж на девятимиллионной аудитории. При этом Фиджи Симо уходит из OpenAI ровно тогда, когда Альтман остаётся один на один с governance. Центр силы в AI смещается: раньше выигрывал тот, у кого лучшая модель, теперь — тот, кто контролирует API-отношения с разработчиком. Модели становятся взаимозаменяемыми (Meta буквально эмулирует форматы конкурентов), а вот дистрибуция, цена и лояльность девелопера — нет.
