**Нетехнический project manager — stress management app за 6 недель на Claude Code**

На конференции Code with Claude 2026 Anthropic показал кейс, который стал одним из самых обсуждаемых в зале: проджект-менеджер без навыков программирования построил и выпустил приложение для управления стрессом за шесть недель, используя исключительно Claude Code.

Автор — не разработчик. До этого проекта он не писал production-код самостоятельно. Идея пришла из личного опыта: стандартные приложения для медитации и стресс-менеджмента казались ему слишком универсальными и не учитывали контекст рабочей среды. Он знал, что нужно пользователям — просто не умел это кодить.

Весь процесс разработки шёл через диалог с Claude Code: от архитектуры до деплоя. Шесть недель — от первого промпта до App Store. Ни один профессиональный разработчик к проекту не привлекался. Автор описывал задачи на естественном языке, Claude генерировал код, он тестировал — и так по кругу.

Кейс примечателен не столько техническими деталями, сколько тем, что Anthropic включил его в keynote собственной конференции как образцовый пример нового класса создателей: людей с доменной экспертизой и нулевой технической подготовкой, которые теперь могут самостоятельно доходить до shipped product. Это прямое подтверждение тезиса, который Anthropic транслировал весь день: барьер между "знаю, что нужно" и "умею сделать" исчезает.

Ключевой takeaway: если у вас есть чёткое понимание проблемы в своей нише — технические навыки больше не являются блокером для запуска. Claude Code достаточно хорошо понимает намерение, чтобы довести нетехнического человека до работающего продукта в реальных сторах.
