**🤖 Claude & Anthropic**

• **Claude Sonnet 5** — вышел 30 июня, сразу стал дефолтом в Claude.ai и Claude Code (обновитесь до 2.1.197+). Контекст 1M токенов без повышенных тарифов: 900k-токенный запрос стоит столько же за токен, что и 9k-токенный. Промо-цена $2/$10 per mtok действует до 31 августа, затем стандарт $3/$15. Спроектирован под agentic-задачи: coding, browser, terminal, research. Важный момент: Sonnet 5 использует новый токенизатор — тот же английский текст производит ~1.3–1.4× больше токенов, чем на Sonnet 4.6. Промо-цена частично компенсирует это, но реальные счета стоит проверить на своих промптах.
  ↳ https://www.anthropic.com/news/claude-sonnet-5
  ↳ https://simonwillison.net/2026/Jun/30/claude-sonnet-5/

• **Claude Science (beta)** — не новая модель, но новый продукт. Использует существующие модели (включая Opus 4.8), но оборачивает их в полноценный научный рабочий стол: 60+ баз данных (геномика, протеомика, структурная биология, single-cell research, химия), готовые тулкиты под каждую специализацию. Можно воспринимать как Claude Code, но для лабораторий, а не для engineering. Доступен в beta для Pro, Max, Team, Enterprise на macOS и Linux. Anthropic грантирует до 50 исследовательских проектов по $30K credits; заявки открыты до 15 июля.
  ↳ https://techcrunch.com/2026/06/30/anthropics-claude-science-bets-on-workflow-not-a-new-model-to-win-over-scientists/

• **Claude Code — новые фичи** — вместе с Sonnet 5 как дефолтом: org default models (организации задают модель централизованно), читаемые имена сессий, кликабельные вложения файлов, улучшенный вид агентов. Claude Code Artifacts теперь в beta для Team и Enterprise — превращает работу сессии в живые, шаренные visual-страницы (PR-вокзалтруы, dashboards, release checklists), которые обновляются по мере продвижения работы.
  ↳ https://releasebot.io/updates/anthropic/claude-code

**⚡ Инструменты & Агенты**

• **Devin Fusion** (Cognition, 29 июня) — новый hybrid-model harness для agentic coding. Ключевая идея: запускать два параллельных агента — frontier (Fable-уровень) и sidekick (меньшая модель). Frontier делегирует sidekick-агенту исполнение, сам удерживает планирование, разрешение ambiguity и финальный review. Результат: 35% ниже стоимость при сохранении Fable-уровня на FrontierCode benchmark. 88% merged PR внутри Cognition теперь полностью проходит через automated Fusion router. Примечание: Fable 5 по-прежнему недоступен широкой аудитории — запрет от 12 июня по директиве US government ещё не снят.
  ↳ https://cognition.com/blog/devin-fusion

• **DeepSeek DSpark** (27–28 июня, активно обсуждается 30-го) — speculative decoding framework для DeepSeek-V4, совместный релиз с Пекинским университетом. MIT-лицензия, открытый код. Ускорение per-user generation на 60–85% vs MTP-1 baseline в продакшне. Технически: semi-autoregressive generation + confidence-scheduled validation против suffix decay. Также открыт DeepSpec — тулкит для обучения draft-моделей под Qwen3 и Gemma.
  ↳ https://www.marktechpost.com/2026/06/27/deepseek-releases-dspark-a-speculative-decoding-framework-that-accelerates-deepseek-v4-per-user-generation-60-85-over-mtp-1/

• **MCP экосистема** — 19 831+ серверов, 97M ежемесячных SDK-загрузок. 30 июня зафиксированы обновления в conformance tests, C# SDK, Kotlin SDK, TypeScript SDK и Python SDK. Roadmap 2026 фокусируется на stateless HTTP core (горизонтальное масштабирование без session state) и enterprise readiness (audit trails, SSO, gateway behaviour).
  ↳ https://thenewstack.io/model-context-protocol-roadmap-2026/
