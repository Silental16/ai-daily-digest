**Костянтин Власенко — Respiro: iOS-приложение с 15+ субагентами без единой строки кода до февраля 2026**

Костянтин Власенко работает project manager в Mythical Games. До февраля 2026 он не написал ни одной строки кода. Вообще. Не "умел немного джаваскрипта", не "делал сайты на Wix" — просто никогда. Десять лет в управлении проектами, игровая индустрия, Киев.

В феврале он решил построить Respiro — iOS-приложение для научно обоснованного управления стрессом. Не потому что увидел рыночную возможность. Просто хотел приложение, которое ему самому было бы полезно. Инструмент — Claude Code. Подход — спрашивать Claude, как работают agent systems и какие Apple API подойдут под задачу, а потом вместе с ним строить архитектуру.

Вместо того чтобы писать монолитное приложение, Власенко построил систему из 15+ специализированных субагентов: TCA architect agent, Swift developer agent, Metal specialist, code reviewer и другие. Каждый агент отвечает за свой модуль, они работают параллельно. Первый рабочий прототип — 72 часа. До публикации в App Store — шесть недель с итерациями, тестированием и ревью.

Сегодня Respiro живёт в App Store с сотнями активных пользователей. Но, пожалуй, интереснее другой результат: Власенко вернулся в Mythical Games и начал коммитить код прямо в production. Поделился своим Claude-окружением и воркфлоу с командой разработчиков. Менеджер проектов, который раньше ставил задачи инженерам, теперь сам шипит фичи.

Ключевой инсайт: Claude Code — не "помощник для разработчиков". Это инструмент, который позволяет человеку с нулевым кодинг-бэкграундом мыслить системно и строить реальную архитектуру — если этот человек умеет декомпозировать задачи и итерировать. Project management как навык оказался достаточным фундаментом.
