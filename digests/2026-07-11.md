**🔥 Главное**

• **Mistral выпустила Robostral Navigate — первый робо-модель европейской frontier-лаборатории** — 8B vision-language модель, которая водит робота по сложным средам с ОДНОЙ RGB-камеры: ни LiDAR, ни depth-сенсоров. Обучена целиком в симуляции (400K траекторий, 6 000 сцен) плюс online RL, hardware-agnostic — ложится на любой парк роботов. Результат: 76.6% success rate на R2R-CE validation unseen, на 9.7 пункта выше лучшего single-camera подхода. Софтверная AI-лаборатория официально шагнула в physical AI — и сразу с сильным номером.
  ↳ https://mistral.ai/news/robostral-navigate/

За 2026-й робо-компании подняли $55.8 млрд (Dealroom) — почти вдвое больше прежнего рекорда.
  ↳ https://techcrunch.com/2026/07/05/this-humanoid-robotics-company-is-going-public-but-its-ceo-isnt-promising-a-robot-in-your-home-anytime-soon/

**🤖 Claude & Anthropic**

• **Claude Code v2.1.207: Auto mode приходит в облака, дефолт — Opus 4.8** — Ключевое для энтерпрайза: Auto mode теперь работает БЕЗ opt-in на Amazon Bedrock, Google Vertex AI и Microsoft Foundry (раньше требовался env-флаг `CLAUDE_CODE_ENABLE_AUTO_MODE`; выключается через `disableAutoMode` в настройках). Bedrock, Vertex AI и Claude Platform на AWS теперь по умолчанию крутят Opus 4.8. Плюс важные security-фиксы: remote managed settings в `claude -p` тихо записывались как «согласованные» без показа диалога, а `${user_config.*}` в hook-командах теперь отклоняется (shell injection). Заодно починили фриз терминала на очень длинных выводах и порчу `.git/config` после удаления worktree.
  ↳ https://code.claude.com/docs/en/changelog

• **Claude Console: API-ключам можно задать срок жизни** — Разработчики наконец получили expiration dates на API-ключи: пресеты, кастомный срок или Never. Email-напоминания приходят до истечения (для ключей от 7 дней), а Admin API отдаёт поле `expires_at`. Мелочь, которой годами не хватало для нормальной ротации секретов и compliance.
  ↳ https://docs.anthropic.com/en/release-notes/api
