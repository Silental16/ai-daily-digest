**🤖 Claude & Anthropic**

• **Claude Code: auto mode больше не ломает ваш git** — Новый safety layer в auto mode блокирует деструктивные git-команды — `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop` — если пользователь явно не просил удалить локальные изменения. Также заблокированы `git commit --amend` для коммитов, не созданных агентом в текущей сессии, и инфраструктурные destroy-команды (`terraform destroy`, `pulumi destroy`, `cdk destroy`) без явного запроса. Исправлены: тихое завершение хода при ответе только с thinking block, дублирование skills в автодополнении, краши при запуске, зависания macOS TUI.
  ↳ https://releasebot.io/updates/anthropic/claude-code

• **Claude + Apple Foundation Models** — Anthropic подтвердила интеграцию Claude в системный уровень iOS 27, iPadOS 27, macOS 27, visionOS 27 и watchOS 27 через новый Foundation Models framework. Сторонние приложения получат доступ к Claude без отдельного API-ключа. Запуск ОС ожидается осенью 2026.
  ↳ https://releasebot.io/updates/anthropic/claude

**💡 Инсайт дня**

Неделя рисует один последовательный паттерн: AI-гонка переходит из технологической в геополитическую и кадровую. Правительство США заблокировало сильнейшую модель Anthropic по соображениям нацбезопасности — возможно, по наводке конкурента. OpenAI немедленно воспользовалось вакуумом: GPT-5.5 теперь возглавляет бенчмарки доступных моделей и привлекает ключевые таланты Google. Shazeer стоил Google $2.7 млрд — и ушёл меньше чем через два года. ChatGPT при этом теряет рыночное большинство, не теряя лидерства. Три факта рядом: ChatGPT < 50% рынка, Claude Fable 5 недоступен, Shazeer в OpenAI — это не совпадения, а структурное перераспределение сил. Инфраструктурный сигнал добавляет ещё один уровень: когда FERC ускоряет подключение дата-центров в обход многолетних процедур, энергетика становится таким же стратегическим ресурсом AI-гонки, как таланты и модели.
