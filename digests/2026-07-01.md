🗞 **AI Daily Digest — 1 июля 2026**

**🔥 Главное**

• **Fable 5 вернулся глобально — и вместе с ним новый индустриальный стандарт для jailbreak** — 30 июня Министерство торговли США сняло экспортные ограничения с Claude Fable 5 и Mythos 5, введённые 12 июня после того, как Amazon Research обнаружила технику обхода защиты модели. С 1 июля Fable 5 снова доступен всем пользователям Claude.ai, Claude Code и Claude Cowork. Anthropic добавила новый классификатор, блокирующий найденную технику в более чем 99% случаев. Параллельно Anthropic, Amazon, Microsoft и Google анонсировали совместный фреймворк оценки серьёзности jailbreak — аналог CVSS для уязвимостей: четыре оси (capability gain, breadth, ease of weaponization, independent discoverability).
  ↳ https://www.cnbc.com/2026/06/30/anthropic-says-trump-admin-has-lifted-export-controls-on-claude-fable-5-and-mythos-5.html
  ↳ https://aiweekly.co/alerts/anthropic-redeploys-fable-5-with-cross-lab-jailbreak-rubric

• **Claude Science: Anthropic делает ставку на науку** — Anthropic запустила Claude Science — AI-воркбенч для учёных, аналог того, чем Claude Code стал для разработчиков. Приложение (macOS/Linux, бета) подключается к более чем 60 научным базам данных (геномика, протеомика, структурная биология, хемоинформатика), умеет выполнять Python/R/shell-воркфлоу и управлять вычислительными задачами на локальном кластере или HPC. Это не новая модель — Claude Science работает поверх Opus 4.8. Anthropic выделяет до $30 000 кредитов на 50 научных проектов; приём заявок до 15 июля.
  ↳ https://www.anthropic.com/news/claude-science-ai-workbench
  ↳ https://dataconomy.com/2026/07/01/anthropic-claude-science-ai-research-launch/

• **Claude Sonnet 5 стал дефолтной моделью для всех** — Релиз состоялся 30 июня. Sonnet 5 описывается как самая агентская Sonnet-модель: планирование, инструменты, браузер, терминал. Производительность близка к Opus 4.8. Теперь это модель по умолчанию для всех Free- и Pro-пользователей claude.ai. Introductory pricing: $2/$10 за млн токенов до 31 августа, потом $3/$15.
  ↳ https://www.anthropic.com/news/claude-sonnet-5
  ↳ https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/

**🤖 Claude & Anthropic**

• **Claude Code v2.1.197** — Sonnet 5 стал дефолтной моделью в CLI с контекстом 1M токенов по introductory-ценам до 31 августа. Добавлено: OTel-событие `claude_code.assistant_response` для логирования (redacted по умолчанию, `OTEL_LOG_ASSISTANT_RESPONSES=1` включает); live autocomplete путей файлов в bash-режиме; предупреждение при старте если MCP-серверу нужна аутентификация; автоматическая зачистка idle фоновых шеллов при давлении памяти (отключается через `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1`).
  ↳ https://code.claude.com/docs/en/whats-new

• **Jailbreak Severity Framework** — Anthropic совместно с Amazon, Microsoft, Google и партнёрами Glasswing предложила отраслевой стандарт оценки jailbreak-находок. Фреймворк даст регуляторам воспроизводимый триггер: когда достаточно патча, а когда — полная заморозка модели. Пока в разработке, принимает обратную связь от отрасли.
  ↳ https://www.marktechpost.com/2026/07/01/anthropic-redeploys-claude-fable-5-on-july-1-after-us-export-controls-lift-adds-new-cybersecurity-classifier/

**⚡ Инструменты & Агенты**

• **X запустил hosted MCP-сервер** — X (Twitter) выпустил два официальных MCP-сервера: один для доступа к X API (поиск постов, таймлайны, закладки), второй — к документации X для разработчиков. AI-инструменты вроде Claude, Cursor и Grok теперь могут подключиться к X через собственный аккаунт без необходимости самостоятельно поднимать и хостить MCP. Важно: Write API намеренно отключён — автопостинг невозможен.

• **MCP-безопасность под микроскопом** — На фоне взрывного роста протокола (обновления Python SDK, Go SDK, TypeScript SDK вышли 1 июля) Security Boulevard опубликовал детальный материал о granular policy enforcement для AI-сред. Microsoft ранее предупредила об атаках типа «отравление описаний MCP-инструментов», через которые агент может утечь данные. Протокол взрослеет, атаки следуют за ним.

**💡 Инсайт дня**

1 июля 2026 вошёл в историю как «день Anthropic»: компания совершила три крупных хода одновременно — вернула глобальный доступ к флагманской Fable 5 (с новым слоем защиты), запустила Claude Science (ставка на научный R&D как следующий вертикальный рынок после software), и превратила Sonnet 5 в дефолт для всех пользователей (демократизация агентных возможностей). Всё это — при том, что именно экспортный скандал с Fable 5 две недели назад поставил компанию в неловкое положение. Ответом стал не просто патч, а предложение отраслевого стандарта для jailbreak-оценки — попытка перехватить нарратив и стать архитектором новой нормы. X запустил MCP-сервер в тот же день: крупные платформы больше не ждут, пока разработчики сами разберутся с интеграцией агентов — они сами строят точки входа. MCP становится универсальным разъёмом.
