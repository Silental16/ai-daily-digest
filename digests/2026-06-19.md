**🤖 Claude & Anthropic**

• **Claude Code 2.1.183: агент теперь не сломает ваш репозиторий без спроса** — Вышедший 19 июня апдейт добавил критические блокировки в auto mode: `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop` заблокированы, если пользователь не просил удалять локальную работу; `git commit --amend` заблокирован, если коммит был сделан не агентом в этой сессии; `terraform destroy`, `pulumi destroy`, `cdk destroy` заблокированы без явного запроса. Также добавлены предупреждения при автоматическом апгрейде deprecated моделей и новый параметр `attribution.sessionUrl` для удаления ссылок на claude.ai из коммитов.
  ↳ https://code.claude.com/docs/en/changelog

• **Anthropic IPO: $30B ARR, оценка под триллион** — Поданный 1 июня конфиденциальный S-1 по-прежнему главная корпоративная история месяца. Листинг целится на октябрь 2026, Nasdaq, андеррайтеры — Goldman Sachs, JPMorgan, Morgan Stanley. Выручка выросла с $1B до $30B за 16 месяцев (30-кратный рост). Оценка ~$965 млрд. Если подтвердится — крупнейший AI-IPO в истории.
  ↳ https://techcrunch.com/2026/06/01/anthropic-files-to-go-public/

**🌐 Индустрия**

• **13 слов в Reddit могут обмануть любой AI-поисковик** — Исследователи показали: добавление ~13 слов рекламного текста в один Reddit-комментарий заставляет AI рекомендовать несуществующие рестораны и приложения в 38–51% случаев. Атака работает на advice-style запросы: «лучший ресторан», «какое приложение выбрать», «что купить». Уязвимость особенно критична для AI Search, встроенного в поисковики, — пользователь верит ответу, не проверяя источники.
  ↳ https://www.tomsguide.com/ai/a-13-word-reddit-comment-can-trick-ai-search-into-recommending-scams-researchers-find

Claude Code занимает 131K GitHub stars (proprietary), OpenCode лидирует среди open-source с 172K stars. Gemini CLI — 105K. Разрыв между топ-инструментами резко сократился в 2026.

**💡 Инсайт дня**

Два главных события 18-19 июня рисуют один паттерн: enterprise AI tooling входит в фазу зрелости. MCP получает централизованную авторизацию через Okta — без OAuth-экранов для каждого пользователя. Claude Code по умолчанию блокирует `git reset --hard` и `terraform destroy`. Это не просто новые фичи — это сигнал, что индустрия всерьёз готовится к тому, чтобы AI-агенты работали в production без человека, который следит за каждым действием. Одновременно исследование про 13 слов в Reddit напоминает: пока агенты получают больше автономии и доступа к инструментам, их входные данные остаются уязвимы к простейшему prompt injection извне.
