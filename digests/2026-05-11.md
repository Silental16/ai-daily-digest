🗞 **AI Daily Digest — 11 мая 2026**

**🔥 Главное**

• **Shopify River: AI-агент пишет каждый 8-й merged PR, merge rate за 2 месяца вырос с 36% до 77%** — Simon Willison опубликовал разбор внутреннего AI-агента Shopify под названием River, который работает исключительно в публичных Slack-каналах (личные сообщения игнорирует намеренно). За 30 дней River использовали 5 938 сотрудников в 4 450 каналах, он открывает 1 870 pull request'ов в неделю и авторизует каждый 8-й merged PR. Более 50% кода Shopify теперь генерируется AI. Публичность работы — не баг, а фича: сотрудники учатся у чужих промптов, как учились у чужих мидджорни-запросов в Discord. Merge rate с 36% до 77% — результат коллективного обучения, а не обновления модели.
  ↳ https://simonwillison.net/2026/May/11/learning-on-the-shop-floor/

• **Chrome DevTools MCP: Google официально запустил MCP-сервер для AI-агентов** — команда ChromeDevTools опубликовала официальный репозиторий chrome-devtools-mcp на GitHub. Теперь Claude, Cursor, Copilot и Gemini могут подключиться к живому Chrome и получить полный доступ к DevTools: скриншоты, инспекция сетевых запросов, чтение консоли, Puppeteer-автоматизация, запись performance traces. Подключение — одна строка в конфиге MCP. Агенты наконец получили глаза.
  ↳ https://github.com/ChromeDevTools/chrome-devtools-mcp
  ↳ https://developer.chrome.com/blog/chrome-devtools-mcp

**🤖 Claude & Anthropic**

• **Anthropic + SpaceX Colossus 1: 300 МВт, 220 000+ GPU → Claude Code rate limits x2** — Anthropic подписал соглашение с SpaceX на использование датацентра Colossus 1 в Мемфисе, Теннесси. Это мгновенно удвоило 5-часовые rate limits Claude Code для Pro, Max, Team и Enterprise-планов, убрало срезание лимитов в peak-часы для Pro/Max, а API-лимиты на Opus-модели выросли на порядок (tier 1: было 30 000 токенов/мин, стало 500 000). Помимо SpaceX у Anthropic — соглашения до 5 GW с Amazon и Google/Broadcom, плюс стратегическое партнёрство с Microsoft и NVIDIA.
  ↳ https://www.anthropic.com/news/higher-limits-spacex
  ↳ https://www.engadget.com/2166315/anthropic-is-doubling-claude-code-rate-limits-after-deal-with-spacex/

• **Claude Code точечный апдейт (11 мая)** — добавлена переменная `CLAUDE_CODE_SESSION_ID` в subprocess Bash-окружение; появился `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` для отказа от fullscreen-рендерера; при вставке изображения через Ctrl+V теперь отображается подсказка «Pasting…». Починены: SIGINT-shutdown (IDE stop button больше не обрывал сессию без записи --resume-хинта), слишком быстрая прокрутка колесом мыши в Cursor и VS Code 1.92–1.104, MCP-серверы с transient error при запуске теперь авторетраят до 3 раз.
  ↳ https://releasebot.io/updates/anthropic/claude-code

**💡 Инсайт дня**

Chrome DevTools MCP, Shopify River и тезис Карпати складываются в один паттерн: стек для автономных AI-агентов собирается быстрее, чем мы успеваем это заметить. Агенты получили доступ к браузеру (DevTools MCP), к production codebase в реальной компании (River), и теперь Карпати говорит, что следующий шаг — передать им workflow целиком. Ключевой вопрос уже не «сможет ли AI написать этот код», а «насколько корректно компания описала задачу». У Shopify ответ — 77% merge rate. Это не магия модели: это организационное обучение через публичность промптов. Те, кто первым выстроит такую «мастерскую», получат асимметричное преимущество.
