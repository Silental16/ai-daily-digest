💰 **Indie Story**

**Chirag Thummar — ClaudeSkill.com: маркетплейс для Claude Code SKILL.md за 7 дней**

Chirag Thummar — разработчик, который решил проверить на практике один вопрос: сколько реально занимает запуск production-продукта с нуля, если Claude Code делает основную работу? В мае 2026 он опубликовал подробный day-by-day разбор того, как за одну неделю собрал ClaudeSkill.com — открытый маркетплейс для Claude Code AI skills (скиллов в формате SKILL.md стандарта).

За 7 дней он в одиночку запустил платформу с полным production-стеком: авторизацией пользователей, приёмом платежей, поиском по каталогу, поддержкой 8 локалей и индексацией в Google. На момент публикации на маркетплейсе было размещено 2 800+ skills. Не прототип, не MVP «на коленке» — работающая платформа с реальными платящими пользователями.

Ключевая механика — Thummar использовал Claude Code не как autocomplete, а как полноценного соавтора архитектуры. Он описывал задачу на день, давал агенту контекст, ревьюил результат, итерировал. По его словам, самый ценный инсайт — правильный scope за итерацию: не «сделай всё», а «сделай авторизацию с вот такими ограничениями». Каждый из 7 дней заканчивался рабочим, задеплоенным инкрементом.

Выбор ниши показателен: SKILL.md — стандарт, который только набирает momentum в Claude Code-экосистеме. Thummar нашёл окно до того, как рынок оформился, и занял его за неделю. Для сравнения: классический solo-запуск продукта с похожим feature set занял бы месяцы.

Главный takeaway: Claude Code меняет не только скорость разработки, но и размер рыночного окна, которое успевает закрыться до твоего запуска. 7 дней — это уже конкурентоспособное время выхода на рынок для нишевого B2D-продукта.
