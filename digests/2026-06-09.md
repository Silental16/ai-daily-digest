**🔥 Главное**

• **Anthropic выпустила Claude Fable 5 — первая публичная Mythos-класс модель** — Главный анонс дня: Anthropic открыла широкий доступ к Claude Fable 5, построенной на архитектуре Claude Mythos, которую компания ещё в апреле признала «слишком мощной для публики». Решение — production-grade safety wrapper: в доменах кибербезопасности, биологии, химии и дистилляции модель автоматически падает обратно на Opus 4.8. По данным Anthropic, 95% сессий прошли полностью на Fable без единого fallback. Цена: $10/$50 за M токенов — вдвое дороже Opus 4.8, но в 2.5 раза дешевле, чем Mythos Preview.
  ↳ https://www.anthropic.com/news/claude-fable-5-mythos-5

• **Benchmarks Fable 5: 95% SWE-bench Verified, #1 FrontierCode** — На SWE-bench Verified модель набрала 95.0%, на SWE-bench Pro — 80.0%, 1932 Elo на GDPval-AA. Лидирует на FrontierCode. Контекстное окно — 1M токенов, поддержка текста, изображений, файлов. Одновременно вышла обновлённая версия Claude Mythos 5 — по-прежнему только через Project Glasswing для правительственных и оборонных партнёров.
  ↳ https://artificialanalysis.ai/models/claude-fable-5

**🤖 Claude & Anthropic**

• **Claude Fable 5 сразу доступна на GitHub Copilot (GA) и Amazon Bedrock** — Параллельно с API-релизом, Fable 5 запущена в GitHub Copilot как generally available и на Amazon Bedrock. Юридическая платформа Harvey также объявила о доступности модели. Model ID: `claude-fable-5`.
  ↳ https://github.blog/changelog/2026-06-09-claude-fable-5-is-generally-available-for-github-copilot/

• **Claude Code: safe mode, /cd команда и disableBundledSkills** — Новый релиз Claude Code добавляет флаг `--safe-mode` (и env `CLAUDE_CODE_SAFE_MODE`) для запуска без кастомизаций — все CLAUDE.md, плагины, skills, hooks и MCP-серверы отключаются. Удобно для диагностики проблем. Добавлена `/cd` команда для смены рабочей директории без разрыва prompt cache. Настройка `disableBundledSkills` скрывает встроенные skills и slash-команды. Улучшена надёжность remote sessions, background agents и enterprise policy enforcement.
  ↳ https://releasebot.io/updates/anthropic/claude-code

• **Новый Swift package: Claude + Apple Foundation Models** — В день WWDC Anthropic выпустила Swift package, позволяющий передавать typed Swift outputs в Claude для multi-step reasoning, code generation и web search с поддержкой StreamUI в SwiftUI. Прямой ответ на открытие Apple AI Extensions.
  ↳ https://releasebot.io/updates/anthropic/claude
