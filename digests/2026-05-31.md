• **Claude Opus 4.8 — детали после первых трёх дней в продакшне** — Модель, вышедшая 28 мая, набирает 88.6% на SWE-bench Verified и 69.2% на SWE-bench Pro — 121 Elo-пункт впереди GPT-5.5. **⚡ Инструменты & Агенты**

• **Claude Code Dynamic Workflows — первая волна реальных кейсов** — Через 72 часа после запуска в X и Reddit появились развёрнутые отчёты: команды запускают 30–80 параллельных агентов на рефакторинг монорепозиториев, генерацию тест-сьютов и code review циклов. Задачи на день выполняются за 20–40 минут. Новая парадигма: один промпт → оркестрация десятков агентов в фоне → результат.
  ↳ https://code.claude.com/docs/en/whats-new

• **MCP 2026 Roadmap: stateless-ядро и enterprise-hardening** — Официальный роадмап Model Context Protocol сместил фокус с release milestones на четыре приоритетных направления: stateless transport (round-robin балансировка без sticky sessions), рафинирование Tasks primitive с retry semantics, governance через Working Groups, и enterprise-readiness (audit trails, SSO-auth, config portability). RC спецификации заморожен с 21 мая; финальная публикация — 28 июля. Отдельно: NSA опубликовал security guidance по MCP.
  ↳ https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/
  ↳ https://www.nsa.gov/Portals/75/documents/Cybersecurity/CSI_MCP_SECURITY.pdf

**💡 Инсайт дня**

Microsoft тратила достаточно на Claude Code, чтобы почувствовать боль — и этот факт говорит больше любых рыночных отчётов. Copilot запустили в 2021 году как «будущее разработки». Сейчас, в 2026-м, собственные инженеры Microsoft выбирают сторонний инструмент — и компания вынуждена реагировать экстренным строительством конкурента. Project Polaris выйдет в августе. Но Claude Code уже захватил привычки, воркфлоу и тактические знания команд. Переключить инструмент — не то же самое, что переключить LLM в промпте. Это поведенческая инерция. Anthropic это знает. Поэтому dynamic workflows, поэтому managed agents, поэтому 20+ legal MCP коннекторов — они строят не «лучшую модель», а необратимую экосистему.
