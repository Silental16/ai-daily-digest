🗞 **AI Daily Digest — 3 июня 2026**

**🔥 Главное**

• **Uber вводит лимит $1 500/месяц на Claude Code и Cursor** — После того как компания потратила годовой бюджет на AI-инструменты за 4 месяца, CTO Uber объявил о жёстких ограничениях: каждый сотрудник теперь может тратить не более $1 500 в месяц на каждый agentic coding-инструмент (Claude Code и Cursor учитываются отдельно). Ранее Uber активно поощрял использование AI — вплоть до внутренних лидербордов по активности. Лимиты можно превысить с разрешения руководства, и у каждого есть дашборд для отслеживания расходов.
  ↳ https://techcrunch.com/2026/06/02/uber-caps-employee-ai-spending-after-blowing-through-budget-in-four-months/

• **Microsoft представил MAI-Thinking-1 на Build 2026 Day 2** — Первая собственная reasoning-модель Microsoft: 35B активных параметров при ~1T суммарных (sparse MoE), контекст 256K, обучена с нуля без дистилляции данных OpenAI. 97% на AIME 2025, сравнима с Opus 4.6 на SWE-Bench Pro. Доступна в Foundry в private preview. Параллельно анонсирован MAI-Code-1 и Copilot Agent Mode для M365 (запуск в конце июня).
  ↳ https://www.absolutegeeks.com/article/tech-news/microsoft-unveils-mai-thinking-1-and-new-ai-models-at-build-2026/

  ↳ https://uk.investing.com/news/stock-market-news/anthropic-launches-services-track-for-claude-partner-network-93CH-4711875

  ↳ https://fortune.com/2026/06/01/anthropic-confidentially-files-ipo-965-billion-valuation/

• **Claude Code — деградация сервиса** — 3 июня с раннего утра часть пользователей испытывала проблемы с Claude Code (code review, security review, web sessions). Инцидент закрыт в 07:36 UTC. Также в недавнем обновлении: поддержка Opus 4.8, fallback-модель при недоступности основной, улучшенный детектор data exfiltration, Vim-режим с обратным поиском по истории.
  ↳ https://status.claude.com/

**💡 Инсайт дня**

История Uber — зеркало для всей индустрии. Компания сначала геймифицировала использование AI-инструментов через лидерборды, а теперь вводит лимиты после бюджетного провала. Это не провал AI — это сигнал, что agentic coding перешёл из разряда «нишевого эксперимента» в реальную операционную статью. $1 500/месяц на одного инженера — это $18 000/год; при тысячах инженеров деньги огромные. Следующий шаг очевиден: корпоративные tier-ы с фиксированными enterprise-ценами. Anthropic уже движется туда с Services Track и надвигающимся IPO. Гонка за корпоративные контракты только начинается.
