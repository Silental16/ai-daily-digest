💰 **Indie Story**

**Sarah Perl — Stella: контент-криэйтор без кода до $300K MRR за два месяца**

Sarah Perl — криэйтор с 1,2 млн подписчиков в Instagram и 2,8 млн в TikTok — никогда не писала код. В мае 2026-го она решила монетизировать нишу, которую хорошо знала изнутри: медитации, аффирмации, визуализация целей. Вместо найма разработчика она взяла Claude Code.

Приложение называется Stella. Это AI-ассистент для «манифестации»: генерирует персонализированные аффирмации и визуализации, адаптированные под настроение, время суток и конкретную цель пользователя. Интерфейс намеренно минималистичный — никакого перегруза функциями. Sarah строила стек из трёх инструментов: Claude Code для кода, обычный Claude для дизайн-решений и Google AI Studio для части генеративных задач. MVP был рабочим за два дня. Полноценная production-версия — за два-три месяца.

Технического бэкграунда у неё не было никакого — только понимание аудитории и скорость итераций. «Скорость — это всё», — формулирует она свой подход. Большинство конкурентов в нише либо переусложнены, либо выглядят как продукты 2018-го года.

Результат: через два месяца после запуска Stella пересекла $300 000 MRR (~$3,6 млн ARR), набрав около 12 000 платящих подписчиков и 200 000+ загрузок. По данным июльского эпизода подкаста Starter Story, к июлю показатель продолжал расти.

Ключевой takeaway: дистрибуция победила технологию. Sarah пришла с готовой аудиторией в нишу, где ни одного качественного продукта с реальным AI не существовало. Claude Code убрал единственный барьер — разработку. Когда инструмент делает продукт, а создатель приносит доступ к аудитории и глубокое понимание ниши — итого это $300K MRR за шестьдесят дней без единого внешнего инвестора.
