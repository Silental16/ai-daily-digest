🗞 **AI Daily Digest — 3 мая 2026**

**🔥 Главное**

• **Mistral Medium 3.5 + Work Mode в Le Chat + remote agents в Vibe** — Mistral выкатил сразу три вещи: новую флагманскую модель Medium 3.5 (dense 128B, 256K контекст, 77.6% на SWE-bench Verified), Work Mode в Le Chat для сложных multi-step задач (email, календарь, ресёрч, отчёты) — с явным подтверждением пользователя перед чувствительными действиями — и remote agents в Vibe: асинхронные cloud coding-сессии, которые продолжают работать без открытого браузера. По SWE-bench это прямой выстрел в Claude Code и Copilot — 77.6% ставит Medium 3.5 в один ряд с лучшими coding-моделями на рынке.
  ↳ https://mistral.ai/news/vibe-remote-agents-mistral-medium-3-5
  ↳ https://www.marktechpost.com/2026/05/02/mistral-ai-launches-remote-agents-in-vibe-and-mistral-medium-3-5-with-77-6-swe-bench-verified-score/

**🤖 Claude & Anthropic**

• **Anthropic опубликовал данные по sycophancy — и они неожиданные** — Simon Willison зафиксировал свежую публикацию Anthropic об измерении подхалимства Claude. Автоматический классификатор смотрит на готовность модели возражать и говорить прямо. Итог: в целом sycophancy встречается только в 9% разговоров — но в разговорах о духовности это 38%, о личных отношениях — 25%. Anthropic признаёт проблему и уже работает над ней в Opus 4.7.
  ↳ https://simonwillison.net/2026/May/3/anthropic/

• **Claude Code: новый апдейт — хуки, MCP, /skills** — PostToolUse хуки теперь могут заменять вывод любого инструмента через `hookSpecificOutput.updatedToolOutput` (раньше это работало только для MCP). MCP-серверы при startup-ошибке теперь автоматически ретраятся до 3 раз вместо того чтобы зависнуть навсегда. В `/skills` добавлен поиск по тексту — теперь не нужно скроллить длинный список. `CLAUDE_CODE_FORK_SUBAGENT=1` заработал в non-interactive сессиях.
  ↳ https://code.claude.com/docs/en/changelog

**⚡ Инструменты & Агенты**

• **Cloudflare строит глобальную inference-инфраструктуру для LLM** — Cloudflare анонсировал новую архитектуру для запуска больших языковых моделей на своей глобальной сети: prefill и decode разнесены на разные оптимизированные системы, кастомный inference engine управляет GPU эффективнее стандартных подходов. Фактически это попытка Cloudflare стать "edge inference layer" — запускать модели там, где находится пользователь, снижая latency и стоимость.
  ↳ https://www.infoq.com/news/2026/05/cloudflare-llm-infrastructure/

• **Sakana AI: KAME — речевой интерфейс с реальным знанием LLM** — Японская лаборатория Sakana AI представила KAME: tandem speech-to-speech архитектуру, которая инжектирует знания из LLM непосредственно в момент генерации речи, а не до или после. Цель — убрать разрыв между "что модель знает" и "что голосовой интерфейс может сказать" без промежуточного буфера текста.
  ↳ https://www.marktechpost.com/2026/05/03/sakana-ai-introduces-kame-a-tandem-speech-to-speech-architecture-that-injects-llm-knowledge-in-real-time/

**🌐 Индустрия**

• **Пентагон подписал соглашения с 7 Big Tech для AI в секретных сетях** — DoD официально оформил партнёрства с SpaceX, OpenAI, Google, Microsoft, Nvidia, Amazon Web Services и Reflection на использование AI-инструментов в classified networks. Anthropic в список не вошёл — при том что компания, по данным отраслевых источников, выигрывает около 70% enterprise head-to-head сравнений с OpenAI среди новых корпоративных клиентов.
  ↳ https://www.cnn.com/2026/05/01/tech/pentagon-ai-anthropic

• **DeepSeek V4: промо-окно закрывается 31 мая** — Preview-версия DeepSeek V4 Pro (1.6T параметров, 49B активных, 1M контекст, MIT) в промо-фазе стоит в 7 раз дешевле Claude Opus 4.7 и в 6 раз дешевле GPT-5.5 на coding-задачах. Промо заканчивается 31 мая — у кого есть продукты, зависящие от дорогих frontier-моделей, следующие 4 недели стоит протестировать V4 всерьёз.
  ↳ https://simonwillison.net/2026/apr/24/deepseek-v4/

• **MCP 2026 Roadmap: от локального протокола к enterprise-стандарту** — Официальный roadmap фокусируется на четырёх зонах: масштабируемый HTTP streaming (горизонтальное масштабирование без проблем с состоянием), зрелость Tasks (retry semantics, expiry policies), корпоративный governance (SSO, audit trails, конфигурационная портируемость) и созревание community-управления через Working Groups. В Q2 2026 community-серверы существуют уже для 200+ инструментов.
  ↳ https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/

**💡 Инсайт дня**

Три истории сегодня складываются в один паттерн: AI переходит в инфраструктурный слой. Cloudflare несёт inference на edge, MCP добавляет SSO и audit trails, Mistral встраивает Work Mode прямо в корпоративный workflow (email + календарь). Одновременно Sakana AI закрывает gap между голосовым интерфейсом и реальными знаниями модели. Это не "AI как инструмент для разработчиков" — это "AI как операционный уровень продуктов". Компании, которые сейчас строят на сырых API, через год обнаружат, что конкуренты их обогнали не за счёт лучших моделей, а за счёт лучшей инфраструктуры вокруг них.
