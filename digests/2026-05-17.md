**⚡ Инструменты & Агенты**

• **Grok Build vs Claude Code — технические детали** — Помимо 8 параллельных агентов и 2M-токенного контекста, Grok Build имеет Heavy Architecture с 16 sub-models в одном inference pass. Принципиальное отличие от Claude Code: Grok Build не имеет интеграции с VS Code/JetBrains/Web — только terminal. Claude Code работает везде: shell, IDE extensions, GitHub Actions, web и mobile. Цена входа: $99/мес против $20-100/мес у Claude Code Max/Pro.
  ↳ https://www.engadget.com/2173482/xai-coding-agent-grok-build/
  ↳ https://kingy.ai/ai/xai-drops-grok-build-an-agentic-cli-that-wants-to-live-in-your-terminal/

• **OpenAI запустил mobile preview для coding agent** — Отдельная история в тени Grok Build: OpenAI выкатил мобильный интерфейс к своему coding agent. Можно просматривать диффы, одобрять команды и направлять активные сессии прямо со смартфона — тяжёлые вычисления остаются на десктопе. Асинхронное взаимодействие с агентом с телефона — паттерн, который Claude Code уже реализовал через push-нотификации.
  ↳ https://codenewsletter.ai/p/openai-drops-mobile-preview-xai-ships-grok-build-its-first-cli-coding-agent

**💡 Инсайт дня**

За последнюю неделю: Anthropic запустил Claude for Small Business, xAI — Grok Build, OpenAI — мобильный агент, а послезавтра Google покажет agentic Gemini на I/O. Coding agent wars вышли на финишную прямую первого акта: у каждого крупного игрока теперь есть свой terminal agent. Но разрыв не в модели и не в числе агентов — разрыв в интеграции.
