**🔥 Главное**

• **Anthropic + Goldman + Blackstone: $1.5B joint venture против Big Consulting** — Anthropic вместе с Blackstone, Goldman Sachs и Hellman & Friedman запустила новую AI-сервисную компанию с $1.5 млрд committed capital. Структура: инженеры Anthropic встраиваются напрямую в операции mid-size компаний из портфелей PE-фондов — как у Palantir, но с Claude под капотом. Общие партнёры: General Atlantic, Apollo Global, GIC (Сингапур), Sequoia. Примечательно: OpenAI в тот же день анонсировала аналогичный JV с TPG и Bain Capital. Обе компании одновременно объявили войну McKinsey и BCG.

**🤖 Claude & Anthropic**

• **Claude Security — публичная бета для Enterprise** — Anthropic официально запустила Claude Security в public beta. Продукт на базе Opus 4.7: сканирует полные enterprise-репозитории, отслеживает data flows между файлами, находит уязвимости, генерирует патчи с объяснением confidence level и severity. Multi-stage validation pipeline снижает false positives. Экспорт в Slack, Jira, CSV и Markdown. Scheduled и targeted scans. Сейчас доступно только Enterprise-клиентам, для Team и Max — скоро.
  ↳ https://www.helpnetsecurity.com/2026/05/04/anthropic-claude-security-public-beta/
  ↳ https://cybersecuritynews.com/claude-security-public-beta/

• **Пентагон исключил Anthropic из classified-network сделок** — DoD подписал соглашения с SpaceX, OpenAI, Google, NVIDIA, Microsoft, AWS, Oracle и Reflection AI на использование AI в секретных сетях (IL6/IL7). Anthropic в списке нет — компания отказалась убрать guardrails для автономного оружия и массовой слежки. Белый дом, по данным источников, возобновил переговоры с Anthropic после серии последних техническихъ анонсов компании. Парадокс: Anthropic теряет государственные контракты именно потому, что придерживается своей safety-позиции — но эта же позиция помогает ей выигрывать до 70% enterprise head-to-head сравнений.
  ↳ https://www.ghacks.net/2026/05/04/pentagon-signs-ai-deals-with-openai-google-microsoft-nvidia-and-others-cutting-out-anthropic/
  ↳ https://www.defensenews.com/news/pentagon-congress/2026/05/01/pentagon-freezes-out-anthropic-as-it-signs-deals-with-ai-rivals/

**⚡ Инструменты & Агенты**

• **HUMAIN ONE on AWS — enterprise OS для AI-агентов** — Саудовская AI-компания HUMAIN (за ней стоит суверенный фонд PIF) объявила HUMAIN ONE: первую в отрасли enterprise-grade операционную систему для автономных AI-агентов, построенную на AWS. Компоненты: HUMAIN Code, HUMAIN Guardian, HUMAIN Eye, H2O Platform + SDK и HUMAIN Fabric для data governance. Доступно через AWS Marketplace в 39 global regions. Совместные инвестиции в инфраструктуру Саудовской Аравии — $5 млрд с 2025 года.
  ↳ https://www.prnewswire.com/in/news-releases/humain-one-powered-by-aws-will-be-the-industry-s-first-enterprise-grade-operating-system-for-building-deploying-and-governing-autonomous-ai-agents-at-scale-302761241.html

• **Jama Software: первый MCP Server для инженерного менеджмента** — Jama Connect (версия 9.35) стал первым enterprise-инструментом для управления требованиями с нативным MCP Server. Концепция "Spec Driven Development": AI-агенты читают спецификации напрямую из Jama через MCP и генерируют код, тесты и документацию строго в рамках требований. Позиционирование: повышение quality and compliance для multi-disciplinary engineering teams.
  ↳ https://www.globenewswire.com/news-release/2026/05/04/3286889/0/en/Jama-Software-Launches-Model-Context-Protocol-MCP-Server.html

**💡 Инсайт дня**

Сегодняшний день покажут в учебниках как "день, когда AI-лаборатории атаковали консалтинг". Anthropic и OpenAI оба анонсировали Wall Street JV в один и тот же день — случайность это или синхронизация с рыночным окном, неясно. Но структура сигнала очевидна: модели стали commodity-достаточно хорошими, что дифференциатор теперь не "чья модель лучше", а "кто умеет её внедрять в enterprise-операции". Одновременно Anthropic запускает Claude Security — прямой удар по security consulting. HUMAIN ONE претендует на роль AI-инфраструктуры для целых регионов. Все три истории про одно: AI перестаёт быть инструментом и становится операционным слоем бизнеса. Те, кто строит на голых API без стратегии внедрения, рискуют проиграть не конкурентам, а именно этим сервисным слоям.
