**🤖 Claude & Anthropic**

• **Code with Claude London: MCP tunnels и self-hosted sandboxes** — Параллельно Google I/O, в Лондоне Anthropic объявила два ключевых enterprise-обновления для Claude Managed Agents. MCP tunnels (research preview): агенты обращаются к MCP-серверам внутри корпоративной сети через один исходящий коннект — без открытых входящих портов, трафик зашифрован end-to-end. Self-hosted sandboxes (public beta): выполнение инструментов агентов на собственной инфраструктуре через Cloudflare, Daytona, Modal или Vercel — Anthropic управляет только оркестрацией и контекстом. Это прямой ответ на главный enterprise-blockers: агенты больше не обязаны уходить за периметр безопасности компании. Дополнительно: удвоены rate limits Claude Code, анонсированы три новых режима Managed Agents (Multiagent Orchestration, Outcomes, Dreaming), выпущены 20+ MCP-коннекторов для юридических фирм и 12 практических плагинов.
  ↳ https://thenewstack.io/anthropic-mcp-tunnels-sandboxes/
  ↳ https://the-decoder.com/anthropic-adds-self-hosted-sandboxes-and-mcp-tunnels-to-claude-managed-agents/

**⚡ Инструменты & Агенты**

• **Claude Code: /resume для фоновых сессий, /model per-session и fix 75-секундного зависания** — Свежее обновление: /resume теперь работает для сессий, запущенных через claude --bg или agent view (отображаются с маркером bg в списке). /model меняет модель только для текущей сессии; клавиша d в model picker устанавливает дефолт для новых сессий. Исправлено зависание при старте до 75 секунд, если api.anthropic.com недоступен (captive portal, VPN, firewall) — side-channel API calls теперь таймаутятся за 15 секунд. Плагины получили строгий контроль зависимостей: claude plugin disable блокируется, если другой плагин зависит от цели, с подсказкой полной цепочки для отключения. "Extra usage" переименован в "usage credits".
  ↳ https://code.claude.com/docs/en/changelog
  ↳ https://releasebot.io/updates/anthropic/claude-code

• **MCP Roadmap 2026: четыре приоритета до конца года** — Официальный роадмап Model Context Protocol смещается от релиз-планирования к рабочим группам. Четыре направления: Transport Evolution (HTTP для remote-серверов без костылей под балансировщики нагрузки), Agent Communication (retry semantics и expiry policies для долгих асинхронных задач), Governance Maturation (contributor ladder, делегирование review в рабочие группы), Enterprise Readiness (audit trails, SSO-интеграция, gateway behavior, config portability). SEP вне этих приоритетов — в конец очереди, отдельно предупреждают о конечной пропускной способности мейнтейнеров.
  ↳ https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/
