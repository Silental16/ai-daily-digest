**🤖 Claude & Anthropic**

• **Code with Claude London: MCP tunnels и self-hosted sandboxes** — На лондонском ивенте (первое developer-мероприятие Anthropic за пределами США) анонсированы два инфраструктурных апдейта для Claude Managed Agents. Self-hosted sandboxes (public beta): компании могут запускать tool calls агентов на собственной инфраструктуре или через партнёров — Cloudflare, Daytona, Modal, Vercel. MCP tunnels (research preview): лёгкий gateway открывает одно исходящее зашифрованное соединение, позволяя агентам обращаться к внутренним MCP-серверам без публичных эндпойнтов и правок файрволла. Оба обновления направлены на одно: дать enterprise-командам полный контроль над тем, где и как агенты запускают инструменты.
  ↳ https://the-decoder.com/anthropic-adds-self-hosted-sandboxes-and-mcp-tunnels-to-claude-managed-agents/
  ↳ https://www.infoq.com/news/2026/05/claude-mcp-tunnels/

• **Claude для малого бизнеса и Opus 4.7 Fast mode** — Anthropic запустила пакет Claude for Small Business с готовыми коннекторами к QuickBooks, PayPal, HubSpot, Canva, DocuSign, Google Workspace и Microsoft 365. Отдельно: Claude Opus 4.7 получил Fast mode в research preview — значительно ускоренная генерация токенов с premium-прайсингом.
  ↳ https://releasebot.io/updates/anthropic/claude

• **Claude Code v2.1.146** — Команда `/simplify` переименована в `/code-review` с опциональным уровнем усилий (например, `/code-review high`). Исправлены баги: Windows PowerShell падал с "command line is invalid" при установке через winget/Microsoft Store (регрессия с v2.1.124), MCP-серверы с пагинацией теряли элементы после первой страницы, строб full-screen в Windows Terminal при стриминге.
  ↳ https://releasebot.io/updates/anthropic/claude-code

**⚡ Инструменты & Агенты**

• **Simon Willison запустил Datasette Agent** — 21 мая Willison анонсировал первый релиз Datasette Agent — расширяемого AI-ассистента для Datasette, своей популярной open-source утилиты для публикации и исследования данных. В тот же день вышли datasette-agent-charts 0.1a2 (Observable Plot-диаграммы) и datasette-agent-sprites 0.1a0 (инструменты для работы с Fly Sprites). Ещё один кирпичик в экосистему LLM-powered data tools от одного из самых продуктивных open-source разработчиков в AI-пространстве.
  ↳ https://simonwillison.net/2026/May/21/datasette-agent/

• **NSA выпустила руководство по безопасности MCP** — Artificial Intelligence Security Center (AISC) при АНБ США опубликовал Cybersecurity Information Sheet с требованиями к безопасному развёртыванию Model Context Protocol. Выделены конкретные риски: ошибки сериализации, нечёткие trust boundaries, злоупотребление инструментами агентов, неявные доверительные отношения между серверами. Рекомендации: изолировать инструменты по data classification zones, логировать все вызовы включая параметры и идентификаторы. Первый официальный сигнал от регуляторов безопасности, что MCP вышел из зоны экспериментов в зону compliance.
  ↳ https://www.nsa.gov/Press-Room/Press-Releases-Statements/Press-Release-View/Article/4496698/nsa-releases-security-design-considerations-for-ai-driven-automation-leveraging/
