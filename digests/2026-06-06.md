**🔥 Главное**

• **Anthropic + SpaceX: 220 000 GPU и конец лимитов Claude Code** — Anthropic подписала соглашение на использование всей вычислительной мощи дата-центра Colossus 1 от SpaceX — более 300 МВт и 220 000 NVIDIA GPU в рамках одного контракта. Немедленный эффект для разработчиков: пятичасовые лимиты Claude Code удвоены для Pro, Max, Team и Enterprise-планов, ограничения в пиковые часы сняты для Pro и Max, API rate limits для моделей Opus существенно подняты. Это самый крупный compute-контракт Anthropic наряду с ранее объявленными сделками с Amazon (5 ГВт), Google/Broadcom (5 ГВт) и Microsoft/NVIDIA ($30 млрд Azure-ёмкости).
  ↳ https://www.anthropic.com/news/higher-limits-spacex

• **Claude Code v2.1.166 (6 июня)** — Минорный, но важный для production-команд апдейт. Ключевые изменения: настройка `fallbackModel` — до трёх резервных моделей, которые автоматически подключаются при перегрузке основной (конец надписи «overloaded»). Glob-паттерны в позиции tool-name у deny-правил (`"*"` блокирует все инструменты). Усиление безопасности cross-session messaging: сообщения, ретранслируемые из других Claude-сессий через SendMessage, больше не несут user authority — автоматический режим их отклоняет. `MAX_THINKING_TOKENS=0` и `--thinking disabled` теперь корректно отключают thinking у моделей, которые думают по умолчанию.
  ↳ https://code.claude.com/docs/en/changelog

**💡 Инсайт дня**

Anthropic закупает вычислительные мощности у SpaceX и одновременно предупреждает о рисках рекурсивного самоулучшения. Под этим нет противоречия: компания строит единственно возможную позицию — быть достаточно сильными, чтобы задавать правила игры, и достаточно открытыми, чтобы их принимали. 220 000 GPU нужны не для того, чтобы Claude развивал себя сам быстрее — они нужны для того, чтобы разработчики по всему миру имели достаточную пропускную способность. Снятие лимитов Claude Code накануне сезона летних запусков — прямой сигнал: Anthropic хочет, чтобы как можно больше production-продуктов было построено именно на Claude. IPO при оценке $965 млрд становится закономерным следующим шагом. Платформенная война за AI-разработку идёт не между моделями — она идёт между инфраструктурами.

• **fallbackModel в Claude Code** — Наконец встроенный graceful degradation: добавьте в `claude.json` до трёх запасных моделей и забудьте о зависаниях из-за перегрузки основного Opus. Небольшая настройка с большим практическим эффектом.
