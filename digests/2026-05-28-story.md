**Serge Elson — 5 SaaS-продуктов за 8 недель соло с Claude Code**

Серж Эльсон — не стартапер из Кремниевой долины и не serial founder с капиталом за плечами. Он работает в небольшой брюссельской IT-консалтинговой фирме FrontBackConsult (FBC). До 2026 года он управлял проектами, помогал клиентам с Microsoft 365 и разбирался в compliance — но не писал код профессионально. Клиенты хотели продукты, которых не существовало; нанять команду разработчиков было нереально.

В марте 2026 Серж решил попробовать Claude Code. Через 8 недель у него было пять production-ready SaaS-продуктов с enterprise authentication (Clerk), платёжной интеграцией (Stripe), мультиязычным интерфейсом (FR/EN/NL) и полноценным cloud deployment (Vercel + Azure). Полный список: **Tenant-in-the-Box** — платформа M365 E5 governance с 10 автоматизированными модулями и поддержкой NIS2/ISO 27001; **SocialBoost** — AI-генерация контента для соцсетей для малого бизнеса; **DiagBoost** — платформа IT-аудита; **SubsiBoost** — AI-матчер бельгийских субсидий; **FashionBoost** — AI-ассистент для fashion-дизайна. Стек: Next.js, TypeScript, Tailwind, Prisma, n8n, Claude API — и Claude Code как главный инструмент разработки.

Серж работал один. Без CTO, без джунов, без аутсорса. Каждый продукт — от нуля до деплоя. По его словам, Claude Code не просто генерировал код — он проектировал архитектуру, предлагал схемы БД, указывал на edge cases в compliance-логике и сразу писал тесты. «Я описывал задачу на естественном языке, Claude делал 80–90% работы, я проверял и направлял. Не пара-программирование — скорее, я был техническим директором, а Claude — всей командой».

Результат не заставил ждать. На момент публикации в трекере Claude Code (issue #28527) у Сержа в активной стадии переговоров — 7-значный enterprise-контракт. Помимо этого, несколько африканских правительств ведут переговоры о деплое Tenant-in-the-Box для управления M365-инфраструктурой национального масштаба. Параллельно он оценивает потребность в ~4,400 лицензиях Claude Code на 3-летний enterprise-контракт для государственных и корпоративных клиентов в Африке и Европе.

**Ключевой takeaway:** Vibe coding 2026 — это не «написать MVP за выходные». Это «один человек с правильным инструментом может делать то, на что раньше нужна была команда из 5–10 человек». Claude Code снизил барьер не до «начать», а до «довести до production». Серж — не исключение; он — ранний пример того, что будет нормой в 2027.
