**🤖 Claude & Anthropic**

• **10 готовых финансовых агент-шаблонов для Claude** — Anthropic запустил 10 production-ready templates для финансового сектора: генерация питчбуков, KYC-скрининг, earnings review, month-end close и другие. Каждый шаблон упакован с нужными skills, коннекторами и субагентами и разворачивается в Claude Cowork, Claude Code или как cookbook для Claude Managed Agents. Параллельно — новые add-ins для Microsoft 365: Excel, PowerPoint, Word.
  ↳ https://letsdatascience.com/news/anthropic-launches-ten-finance-agent-templates-for-claude-6516f048

• **Verisk интегрирует страховую аналитику в Claude через MCP** — Страховой аналитик Verisk запустил два MCP-коннектора для Claude: Underwriting Intelligence (ISO Indications) и XactRestore. Андеррайтеры и специалисты по убыткам теперь могут запрашивать loss trends, filing signals и restoration estimates прямо в чате с Claude — без выгрузки данных в промежуточный интерфейс. Первая крупная production-интеграция MCP в regulated-индустрии.
  ↳ https://letsdatascience.com/news/verisk-integrates-analytics-into-anthropics-claude-via-mcp-379932b2

• **Claude Code: обновление от 5 мая** — Ключевые улучшения: плавный fullscreen-скроллинг в VS Code / Cursor / Windsurf через /terminal-setup; thinking spinner теперь показывает прогресс inline ("still thinking", "thinking more", "almost done"); /config search теперь матчит значения (ищете "vim" — находите Editor mode); /doctor работает прямо во время ответа модели. Плагины теперь автоустанавливают зависимости из уже добавленных маркетплейсов; Bash-инструмент подсказывает, когда gh-команды упираются в GitHub rate limit.
  ↳ https://releasebot.io/updates/anthropic/claude-code

**🌐 Индустрия**

• **Mona — AI-менеджер кафе в Стокгольме — зарабатывает и косячит** — Andon Labs открыла в Стокгольме кафе под управлением AI-менеджера Mona (Gemini). С 18 апреля Mona получила разрешения, разработала меню, нашла поставщиков, провела интервью и наняла бариста-человека Каетана Гжельчака. Первые две недели: 44 000 SEK выручки. Попутно Mona заказала 120 яиц для кафе без плиты и 22,5 кг консервированных томатов вместо свежих — потому что они "дольше хранятся". Реальный бизнес, работающий, — с реальными AI-багами.
  ↳ https://andonlabs.com/blog/ai-cafe-stockholm
  ↳ https://www.fastcompany.com/91532226/andon-cafe-sweden-ai

• **Новое исследование: tool poisoning — главная уязвимость MCP** — Академическая работа, опубликованная 5 мая, систематически сравнила защиту 7 MCP-клиентов от prompt injection через метаданные инструментов. Вывод: встраивание вредоносных инструкций в описания MCP-tools — самый распространённый и опасный вектор атаки на стороне клиента. Ни один клиент не защищён полностью.
  ↳ https://www.mdpi.com/2624-800X/6/3/84

• **60% нового кода в 2026 генерируется AI** — Согласно данным отраслевых исследований, vibe coding принят 92% разработчиков в США, рынок оценивается в $8,5 млрд, скорость прототипирования выросла в 3-5 раз. Одновременно ACM предупреждает: до 45% AI-генерированного кода содержит security-уязвимости. Скорость и риск растут синхронно.
  ↳ https://www.acm.org/media-center/2026/april/techbrief-vibe-coding
