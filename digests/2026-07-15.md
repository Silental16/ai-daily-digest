**🤖 Claude & Anthropic**

• **Claude Code v2.1.211 — безопасность и проброс текста сабагентов** — Новый флаг `--forward-subagent-text` (и env `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT`) выводит текст и thinking сабагентов в stream-json. Security-фикс: превью разрешений теперь нейтрализуют bidi-override, zero-width и look-alike кавычки — классический вектор prompt-инъекции. Плюс починки: auto-режим больше не перебивает решение `ask` из PreToolUse-хука для несэндбоксного Bash; параллельные сессии не разлогиниваются разом после сна; MCP-серверы плагинов реконнектятся после простоя; сабагенты не откатываются на модель родителя при resume.
  ↳ https://github.com/anthropics/claude-code/releases

• **HIPAA теперь включается self-serve в Enterprise и API** — Админы Claude Enterprise и Claude Platform (API) могут включить HIPAA-конфигурацию в один поток: прочитать BAA, скачать implementation guide, щёлкнуть тумблер — без обращения в sales. Меньше трения для здравоохранения и всех, кто работает с PHI.
  ↳ https://support.claude.com/en/articles/13296973-hipaa-ready-enterprise-plans
