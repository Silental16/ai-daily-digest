**🤖 Claude & Anthropic**

• **Claude Code Routines — в продакшне с 15 мая** — Новая фича доступна для Pro/Max/Team/Enterprise с включённым Claude Code on the web. Routines позволяют запускать автоматизированные coding-воркфлоу по расписанию, через API или в ответ на внешним событиям — всё работает в облаке Anthropic. Запуск: `/schedule` в CLI или прямо на claude.ai/code.
  ↳ https://www.infoq.com/news/2026/05/anthropic-routines-claude/

• **Claude Code v2.1.143 (15 мая)** — Plugin dependency enforcement: `claude plugin disable` теперь отказывает, если другой плагин зависит от отключаемого (с подсказкой disable-chain). Projected context cost в marketplace. Настройка `worktree.bgIsolation: "none"` для репо, где worktrees непрактичны. PowerShell tool теперь передаёт `-ExecutionPolicy Bypass`. Исправлено зависание CLI при corrupt `.credentials.json`.
  ↳ https://github.com/anthropics/claude-code/releases

• **Claude Platform на AWS** — Полный Claude API теперь нативно доступен как AWS-сервис: аутентификация, биллинг и commitment retirement через AWS. Включает managed agents, code execution, web tools, skills, prompt caching и новые модели — без переключения между провайдерами.
  ↳ https://releasebot.io/updates/anthropic/claude
