• **Claude падал на 90 минут — пятый раз за месяц** — В 00:37 UTC 22 июня Anthropic открыла инцидент: elevated error rates сразу на пяти моделях — Opus 4.8, Opus 4.7, Opus 4.6, Sonnet 4.6 и Haiku 4.5. **🤖 Claude & Anthropic**

• **Claude Code получил официальный security-guidance плагин** — Anthropic выпустил бесплатный плагин безопасности для всех пользователей Claude Code (устанавливается через `/plugins`). Плагин работает в три уровня: проверяет правки при редактировании файлов, после каждого model turn и перед коммитом. Покрывает ~25 классов уязвимостей (command injection, XSS, unsafe deserialization и другие). По данным внутреннего тестирования — сократил security-related PR comments на 30–40%.
  ↳ https://cybersecuritynews.com/free-security-plugin-for-claude-code/
  ↳ https://securityweek.com/anthropic-releases-new-claude-sandbox-security-guidance-plugin/

• **Сегодня последний день бесплатного Fable 5** — 22 июня истекает trial window: Fable 5 входил в Pro, Max, Team и Enterprise планы без доплаты с 9 по 22 июня. С 23 июня — только за credits. При этом Fable 5 по-прежнему заблокирован для иностранных граждан по export control directive от 12 июня. Парадоксальная ситуация: модель одновременно переходит на платную модель и остаётся недоступной большинству международных пользователей.
