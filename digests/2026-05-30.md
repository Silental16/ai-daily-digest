**🤖 Claude & Anthropic**

• **Auto mode — теперь на Bedrock, Vertex и Foundry** — Самое тихое, но практически важное обновление выходных: Claude Code auto mode стал доступен в AWS Bedrock, Google Vertex AI и Azure AI Foundry для моделей Opus 4.7 и Opus 4.8. Включить: `CLAUDE_CODE_ENABLE_AUTO_MODE=1`. Enterprise-команды, работающие через облачных провайдеров, наконец получили то, что пользователи claude.ai имели с мая.
  ↳ https://releasebot.io/updates/anthropic/claude-code

• **Пост-аутаж нарратив: зависимость vs. диверсификация** — Судя по дискуссиям в X и Reddit, сегодняшний инцидент разделил сообщество на два лагеря. Первый: «это аргумент за multi-model стратегию». Второй: «это неизбежная цена быть инструментом #1 — AWS тоже падает». Полного post-mortem от Anthropic пока нет.
  ↳ https://statusgator.com/services/claude

**⚡ Инструменты & Агенты**

• **Claude Code — 46% рынка coding tools, Cursor на 19%** — Свежие данные от Pragmatic Engineer подтвердили доминирование: 95% разработчиков используют AI-инструменты еженедельно, 75% — для половины и более своей работы. 55% регулярно используют AI-агентов; среди senior+ инженеров — 63.5%. Большинство жонглирует 2–4 инструментами одновременно.
  ↳ https://newsletter.pragmaticengineer.com/p/ai-tooling-2026

• **Dynamic Workflows в Claude Code — первые реальные тест-кейсы** — Через двое суток после запуска фичи в X появились первые публичные эксперименты: разработчики запускают 30–50 параллельных агентов на рефакторинг монорепозиториев, автоматическую генерацию тест-сьютов и полный цикл code review. Задачи, которые раньше занимали день, выполняются за 15–40 минут.
  ↳ https://code.claude.com/docs/en/changelog

**💡 Инсайт дня**

Сегодняшний аутаж Claude — маленький инцидент, но большой символ. За последние 48 часов Anthropic стала компанией с оценкой почти $1 трлн, вышла Claude Opus 4.8 с dynamic workflows, и тут же — глобальный сбой в субботу. Это не случайное совпадение: спрос после релиза Opus 4.8 был рекордным, нагрузка на инфраструктуру — соответствующей. Пока аналитики считают $47-миллиардный ARR, инженеры пишут скрипты для автоматического failover на Gemini и GPT. Инфраструктурная надёжность становится новым competitive moat в AI. Anthropic это знает — поэтому Project Glasswing, поэтому enterprise SLA, поэтому auto mode на Bedrock и Vertex. Но репутацию строят не только benchmarks — строят uptime.
