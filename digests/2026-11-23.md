**🤖 Claude & Anthropic**

• **Claude Ship: AI-агенты теперь не только проверяют PR, но и утверждают их** — Anthropic запустила Claude Ship — продукт, переводящий Claude из code reviewer в полноправного участника PR-цикла. Code Review уже в GA. Две новые бета-функции: PR Steward (агент мониторит пул-реквесты, находит и фиксит проблемы) и Claude Approvals (агент с правом approve по policy-файлу в репозитории). Доступно для Team и Enterprise на GitHub. Anthropic рекомендует начинать Claude Approvals в режиме observe-only. Это первый случай, когда AI-агент получает формальное право approve, а не только комментарий — граница сдвинулась.
  ↳ https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/

**⚡ Инструменты & Агенты**

• **AWS Strands Box: open-source sandbox для AI-агентов с OS-политиками** — Amazon Web Services выпустила Strands Box — harness-agnostic изолированную среду для запуска coding-агентов (Claude Code, Codex CLI, Kiro CLI и других). OS-enforced политики покрывают shell, файловую систему и сетевой доступ. Целевая аудитория — разработчики, которые запускают агентов в «YOLO mode» с отключёнными permission prompts. Box работает как компаньон к Strands Decider 2B (октябрь 2026). С ростом агентских рантаймов sandbox перестаёт быть академическим понятием и становится требованием enterprise.
  ↳ https://siliconangle.com/2026/11/23/aws-is-making-ai-agents-more-decisive-and-secure-with-its-latest-strands-updates

• **OpenAI Dots: персистентные агенты, которые живут между разговорами** — OpenAI начала ограниченное тестирование Dots — системы агентов, которые продолжают работу в фоне, пока пользователь не открыл ChatGPT. Пока тест идёт среди части Plus-пользователей и Business Standard. Параллель с Cognition Devin Bots (Nov 17) очевидна: архитектура агента «на один сеанс» уступает место постоянно работающему асситенту. Для ChatGPT — самого массового AI-продукта — это смена парадигмы.

На фоне продолжающейся верификации доказательства Гипотезы Римана — ещё одна точка данных: AI + Lean становится стандартным инструментом математической верификации.

**💡 Инсайт дня**

Три несвязанных события 23 ноября складываются в один сигнал. ООН требует обязывающих международных правил. Главный учёный OpenAI предлагает добровольные отраслевые ограничения. Chief AI Officer Meta прямо говорит, что не видит способа сохранить контроль. Всё это — в один день, независимо друг от друга. При этом в том же новостном потоке Anthropic даёт агентам право approve pull requests, AWS открывает песочницу для агентов, а OpenAI тестирует агентов, которые работают круглосуточно без вашего участия. Индустрия одновременно строит и пытается ограничить одно и то же. Самое интересное здесь — не противоречие, а синхронность: похоже, горизонт AGI/ASI теперь оценивается не в «десятилетиях», и это меняет политический климат вокруг AI быстрее, чем любой конкретный релиз модели.
