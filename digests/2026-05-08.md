  ↳ https://www.marktechpost.com/2026/05/08/anthropic-introduces-natural-language-autoencoders-that-convert-claudes-internal-activations-directly-into-human-readable-text-explanations/

EPAM Systems объявил о стратегическом партнёрстве: более 10 000 Claude-certified архитекторов.
  ↳ https://solutionsreview.com/ai-news-for-the-week-of-may-8-updates-from-anthropic-cribl-ibm-more/

**⚡ Инструменты & Агенты**

• **Claude Code: пачка фиксов и новые env vars** — исправлены crash при piping >10 МБ через stdin, баги с MCP tool results (пропадавшие изображения), кликабельность URL в fullscreen, навигация по /config. Добавлены `CLAUDE_CODE_SESSION_ID` и `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1`. MCP-серверы теперь автоматически перезапускаются до 3 раз при transient errors.
  ↳ https://claudefa.st/blog/guide/changelog

• **Snyk + Claude: безопасность кода через AI** — Anthropic интегрировала Claude в платформу Snyk AI Security Platform. Агент находит уязвимости, расставляет приоритеты и генерирует готовые fixes для кода, зависимостей, контейнеров и AI-generated artifacts.
  ↳ https://sdtimes.com/ai/may-8-2026-ai-updates-from-the-past-week-coder-agents-launch-snyk-claude-partnership-opsera-cursor-partnership-and-more/

• **ServiceNow Build Agent встроен во все major IDE** — агент для работы с ServiceNow теперь доступен прямо в Cursor, Claude Code, GitHub Copilot и других инструментах с governance-контролем по умолчанию.
  ↳ https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-Build-Agent-now-works-inside-every-major-AI-coding-tool-governed-by-default/default.aspx

• **AWS MCP Server — General Availability** — managed-сервер даёт AI-агентам безопасный и аудируемый доступ к AWS через MCP. IAM-guard rails, CloudWatch metrics, CloudTrail logging. Агенты могут вызывать любой AWS API через единый инструмент, включая sandboxed Python execution.
  ↳ https://aws.amazon.com/about-aws/whats-new/2026/05/aws-mcp-server/

• **Simon Willison: "Unreasonable Effectiveness of HTML"** — Саймон Уиллисон объяснил, почему попросить Claude выдать объяснение в HTML лучше, чем в Markdown: SVG-диаграммы, интерактивные виджеты, внутренняя навигация — всё это делает ответы значительно удобнее для потребления.
  ↳ https://simonwillison.net/2026/May/8/unreasonable-effectiveness-of-html/

**💡 Инсайт дня**

Два параллельных процесса определяют май 2026: compute-голод и регуляторная гонка. Anthropic — компания с $30B ARR — не успевает строить собственную инфраструктуру и вынуждена арендовать мощности у конкурентов (xAI) и партнёров (Akamai, SpaceX). Одновременно Белый дом предлагает FDA-модель проверки моделей, штаты принимают законы один за другим, а в суды уже летят иски к Character.AI. Рынок растёт настолько быстро, что регуляторы тоже начали гнаться за ним всерьёз. При этом Карпати констатирует смерть «вайб-кодинга» как самодостаточной практики — профессиональные команды переходят на агентные pipeline. Всё идёт к тому, что следующий год станет годом governance и infrastructure, а не моделей.
