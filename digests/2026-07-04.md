🗞 **AI Daily Digest — 4 июля 2026**

**🔥 Главное**

• **Meituan открыла LongCat-2.0: 1.6T параметров, обучен на китайских чипах** — Китайский продуктовый гигант Meituan выложил в open-source под MIT-лицензией модель LongCat-2.0 с 1.6 триллиона параметров — sparse Mixture-of-Experts архитектура с контекстным окном в 1 миллион токенов. Ключевое: модель обучена на отечественных ASIC-суперподах без использования Nvidia GPU. Это первая крупная MoE-модель, доказывающая, что frontier AI возможен полностью на внутренних вычислительных мощностях Китая.
  ↳ https://www.cryptopolitan.com/meituan-longcat-2-0-ai-model-chinese-chips/

• **Grok 4.5 вошёл в закрытую бету у SpaceX и Tesla** — xAI запустил private beta Grok 4.5 для сотрудников SpaceX и Tesla. По имеющимся данным модель содержит ~1.5T параметров и обучена в том числе на данных Cursor. Публичных бенчмарков пока нет — интрига максимальная, особенно на фоне недавнего запуска Claude Sonnet 5.
  ↳ https://www.buildfastwithai.com/blogs/ai-news-today-july-4-2026

**🤖 Claude & Anthropic**

• **Claude Science Beta: мультиагентная рабочая станция для учёных** — Anthropic запустила Claude Science Beta (с 1 июля) для всех платных подписчиков — macOS и Linux. Платформа разворачивает иерархию агентов: coordinating agent принимает задачу на естественном языке, делит её на подзадачи и делегирует специализированным агентам для геномики, single-cell RNA, протеомики, структурной биологии и хемоинформатики. Доступ к 60+ научным базам данных; отдельный reviewer-агент проверяет цитаты и расчёты. Anthropic открыл гранты до $30K в кредитах для исследовательских проектов (заявки до 15 июля).
  ↳ https://www.anthropic.com/news/claude-science-ai-workbench

• **Claude Code: ручной режим теперь по умолчанию** — Июльское обновление Claude Code изменяет разрешительную модель: permission mode меняется с Auto на Manual по умолчанию — больше контроля над тем, что агент делает без явного запроса. AskUserQuestion-диалоги больше не авто-продолжаются. Исправлена мерцающая отрисовка в tmux 3.4+, улучшен вывод для screen reader'ов.
  ↳ https://releasebot.io/updates/anthropic/claude-code

• **Enterprise-аналитика стала детальнее** — 3 июля Anthropic выкатил обновление admin-консоли для Claude Enterprise: расширенная аналитика использования, entitlements на уровне модели, алерты по расходам. Администраторы получили видимость в то, какие команды используют какие модели.
  ↳ https://releasebot.io/updates/anthropic

**⚡ Инструменты & Агенты**

• **Profound Aim — фоновый агент для маркетинга** — 2 июля Profound запустил Profound Aim: always-on background agent, который мониторит позиции бренда в AI-ответах и автоматически оптимизирует контент под visibility в моделях типа Claude и GPT. Показательный сдвиг: маркетинговые агенты выходят из режима "помогает писать посты" в режим "работает без участия человека".
  ↳ https://agentic.ai/news

• **MCP движется к stateless-протоколу** — MCP Kotlin SDK обновлён 4 июля; параллельно идёт работа над release candidate спецификации (финальный релиз запланирован на 28 июля). Главное изменение — протокол становится stateless на уровне транспорта. X (Twitter) запустил hosted MCP-сервер 30 июня — AI-инструменты теперь могут обращаться к X API с правами пользователя.
  ↳ https://thenewstack.io/model-context-protocol-roadmap-2026/
