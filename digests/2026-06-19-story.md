💰 **Indie Story**

**Доктор, техник по ремонту электроники и учитель программирования — победители глобального хакатона по AI-кодингу**

15 июня Anthropic объявил победителей Built with Opus 4.7: a Claude Code Hackathon — глобального виртуального соревнования по созданию агентных приложений. Все три призовых места заняли люди, которых в традиционном смысле не назовёшь разработчиками. Это, пожалуй, самый красноречивый сигнал о том, что вайб-кодинг перестал быть хайпом.

**Кто они и что построили**

Первое место — Bedirhan Keskin, врач из Стамбула. Он создал **MedKit** — голосовой клинический симулятор для студентов-медиков. Студент берёт анамнез у виртуального пациента, назначает лабораторные тесты, ставит диагноз, а система оценивает клиническое мышление по опубликованным протоколам. Keskin использовал Claude Code, не имея бэкграунда в разработке ПО. Он знал, что нужно медицинскому образованию, — и Claude Code превратил это знание в рабочий продукт.

Второе место — Alexis Chapellier, бывший техник по микропайке из небольшого городка во французских Альпах. Его проект **Wrench Board** помогает ремонтникам электроники диагностировать сложные неисправности: пользователь загружает схему платы, система использует мультимодальные возможности Opus 4.7 для визуального анализа и предлагает диагностику. Chapellier годами чинил электронику вручную — он знал, где именно ломается процесс, и просто описал это Claude.

Третье место — Paula Vasquez-Henriquez, учитель информатики из Консепсьона (Чили). Её инструмент **Maieutic** переворачивает логику обучения кодингу: прежде чем написать строчку кода, студент должен объяснить, что он строит и почему. Claude оценивает объяснение — если оно недостаточно чёткое, до кода не добраться. Принудительная артикуляция мышления как предпосылка к написанию кода.

**Почему это важно**

Все три победителя — доменные эксперты, а не инженеры. Они не изучали Python годами, чтобы автоматизировать свою область. Они просто описали проблему, которую знают лучше любого разработчика, и использовали Claude Code как исполнителя.

Это противоположность типичного tech-стартапа, где разработчик ищет проблему под свой стек. Здесь: человек с глубокой экспертизой ищет инструмент — и находит его в AI-агенте. Медицинский тренажёр, написанный врачом. Диагностика электроники, придуманная техником. Педагогический инструмент, спроектированный учителем.

Когда доктор из Стамбула и техник из французских Альп побеждают в хакатоне по кодингу — это не исключение. Это новая норма.
